# tts-free-studios
一个零依赖、单文件的 AI 文字转语音网页工具。直接调用公开 TTS 接口，无需部署后端。

## ✨ 特性
- 📦 **单文件架构**：HTML/CSS/JS 全部集成在一个文件中。
- 🚀 **零配置运行**：无需安装环境，保存为 HTML 即可运行。
- 🎨 **现代化 UI**：卡片式设计，支持响应式布局，完美适配移动端。
- 🔊 **丰富音色**：内置 20+ 种中文音色（男声/女声）。
- 🎛️ **参数调节**：支持自定义语速、音调及 11 种语音风格。

## ⚙️ 接口配置
本项目默认调用公开 API，无需手动配置密钥：
- **API Endpoint**: `https://tts.wangwangit.com/v1/audio/speech`
- **请求方式**: `POST`
